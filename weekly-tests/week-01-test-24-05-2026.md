Python questions

What is a variable in Python?
It is a name that stores value or an object

What does input() return by default?
It returns a string which the user provided

Why do we use int() or float() after input()?
As the default datatype for input() is string, for values like voltage and speed we need to convert to respective data types.

What is the difference between int and float?
int stores the value as a whole number, float stores it as a decimal number

What is a list?
A list is a set of values with number positions.

What does .append() do?
It adds the given values to the list at the end

What does len(values) return?
It returns the length of the list or the number of elements in the list called values

How do you calculate the average of values in a list?
Avg value = sum(list) / len(list)

What is a dictionary?
It is a first data structure beyond lists, it stores key-value pairs.

In this dictionary, how do you access the speed values?

What does git status show?
git status shows the current state of the working directory and staging area.
It tells me which files are modified, untracked, staged, or clean.

What does git add . do?
git add . stages all new, modified, and deleted files for the next commit.

What does git commit -m "message" do?
git commit -m "message" saves the staged changes as a local snapshot with a descriptive message.
commit = local save point
push = upload to GitHub

What does git push origin main do?
git push origin main uploads local commits from the main branch to the remote GitHub repository.

What is the difference between Git and GitHub?
Git is the local version-control software.
GitHub is the online platform that hosts Git repositories, shows commits, and allows sharing/collaboration.
